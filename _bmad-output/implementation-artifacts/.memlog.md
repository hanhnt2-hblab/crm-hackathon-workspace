- (decision) Chốt stack giao diện: React cộng Fluent UI v9. Gói @fluentui/react-components 9.74.6 và @fluentui/react-icons 2.0.337, xác minh trên registry npm ngày 14/08. Lý do: người dùng thử chê giao diện tự chế trông cũ, và nghiên cứu cho thấy Fluent là hệ duy nhất trong ba hệ được nêu tên có công bố token đầy đủ. Không phát minh lại bánh xe.
- (decision) Không cần theme tuỳ biến. Mọi màu trong DESIGN.md đều là token chuẩn của webLightTheme, kể cả màu dòng máy vốn chỉ là colorBrandBackground2 cộng colorBrandStroke1. Bọc FluentProvider theme webLightTheme là đủ, không dùng createLightTheme.
- (decision) Không cài @fluentui/tokens riêng vì gói độc lập đó vẫn là 1.0.0-alpha.24. Lấy tokens từ @fluentui/react-components.
- (assumption) Tên khoá JS trong object tokens mới xác minh gián tiếp qua CSS custom property đọc trên trang Fluent chính chủ, chưa mở được định nghĩa JS vì các gói npm chỉ re-export. Kiểm bằng một dòng Object.keys(tokens) ngay khi dựng.
- (event) CẢNH BÁO THỜI GIAN: @fluentui/react-components có 62 dependencies. Chạy npm install trước ngày thi, đừng để nó ăn vào quỹ 4,5 tiếng.
- (assumption) Quyết định này mới chốt nửa giao diện. Backend, cơ sở dữ liệu, cách gọi mô hình và cách triển khai vẫn là đầu ra của bước bmad-architecture, chưa chạy.
- (decision) Lớp AI chạy Haiku cho mọi lệnh gọi. Ba tầng ghim model đã ghi vào AD-15 của sườn kiến trúc, không lặp lại ở đây.
- (change) Sửa lại dòng chốt stack ghi hôm nay: bước kiến trúc ĐÃ chạy trước đó và đã chốt Node 24.19, Next 16.3.1, React 19.2.8, TypeScript 5.9, Prisma 7.9.1, PostgreSQL 16, Vitest 4.1.10, Agent SDK 0.3.232. Fluent UI là phần BỔ SUNG vào bảng Stack đó, không phải quyết định stack độc lập. Sườn kiến trúc là nguồn có thẩm quyền.
